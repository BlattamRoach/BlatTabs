# BlattamToby — расширение для управления сохранёнными вкладками

Браузерное расширение Chrome (Manifest V3), менеджер сохранённых вкладок, вдохновлённый toby.io / Taby. Позволяет сохранять текущую вкладку с произвольным именем и открывать/удалять их из popup или полноэкранного view.

## Архитектура

```
manifest.json          — Manifest V3, разрешения: tabs + storage
background.js          — Service worker, CRUD вкладок (ключ хранилища: "blattam-tabs")
popup.html / popup.js  — Popup с карточками, поиском и удалением
view.html / view.js    — Полноэкранное окно просмотра вкладок
```

### Хранилище

Ключ `blattam-tabs`, элементы формата:
```js
{ name, url, title?, favIconUrl? }
```

## Ключевое поведение

- **Сохранить текущую вкладку** (`#save-current-tab` в popup) — сохраняет активную вкладку с указанным именем.
- **«+ Добавить вкладку»** (`#add-tab-btn`) — вызывает два `prompt`'а (название и URL), создаёт запись в хранилище без открытия браузерной вкладки.
- **Открыть view** (`#open-view`) — открывает `view.html` в новой вкладке текущего окна через `chrome.tabs.create`. Если нет сохранённых вкладок — ничего не происходит.
- Клик по карточке в popup или view — открывает URL в новой активной вкладке.
- Поиск по имени/заголовку во view.

## Сообщения между компонентами

| Действие | Откуда → Куда | Описание |
|---|---|---|
| `save-current` | popup → background | Сохранить текущую активную вкладку |
| `add-tab` | popup → background | Создать запись вручную (имя + URL) |
| `open-view` | popup → background | Открыть view.html в новой вкладке |
| `get-tab-title` | popup → background | Получить заголовок текущей активной вкладки |
| `open` / `delete` | popup/view → background | Открыть/удалить вкладку по индексу |
| `refresh` | background → view/popup | Обновить список после изменения |

## Загрузка и установка расширения

1. Открыть `chrome://extensions`.
2. Включить **«Режим разработчика»** (правый верхний угол).
3. Нажать **«Загрузить распакованное расширение»** → выбрать директорию проекта.

Разработчик перезагружает расширение после каждого изменения кода.

## Стили и UI

- CSS встроен в HTML (inline styles), без внешних зависимостей.
- Используется `system-ui` для шрифта.
- Цветовая схема: основной `#3498db`, фон `#f5f7fa`.
