# BlattamToby — расширение для управления сохранёнными вкладками

Браузерное расширение Chrome (Manifest V3), менеджер сохранённых вкладок, вдохновлённый toby.io / Taby. Заменяет страницу новой вкладки на свою — при Ctrl+T или клике по «+» в браузере открывается toby с сохранёнными вкладками.

## Архитектура

```
manifest.json          — Manifest V3, chrome_url_overrides.newtab → view.html
background.js          — Service worker, CRUD вкладок (ключ: "blattam-tabs")
popup.html / popup.js  — Popup: кнопка «Сохранить вкладку» с выбором папки
view.html / view.js    — Страница новой вкладки (newtab override) со списком сохранённых вкладок
theme.css              — дизайн-токены (CSS-переменные), общие для view и popup
icons/                 — иконки расширения: icon16.png / icon48.png / icon128.png
build_zip.py           — сборка dist/BlattamToby-v<версия>.zip для Chrome Web Store (только stdlib)
store/                 — материалы магазина: DESCRIPTION.md + 3 PNG-макета
```

### Хранилище

Ключ `blattam-tabs`, элементы формата:
```js
{ name, url, title?, favIconUrl?, folderId? }
```
`favIconUrl` — URL фавикона сайта (ставится при сохранении через popup/hotkey, если у вкладки он есть; data: URL тоже допустим; без него — поле отсутствует, в view отрендерится буквенный fallback).

Ключ `blattam-folders` — папки (категории), формат:
```js
{ id, name, parentId }  // parentId — null (корневая) или id родительской папки (вложенность 1 уровень)
```

Ключ `blattam-theme` (`chrome.storage.local`) — тема: `'light'` (по умолчанию) / `'dark'`.

## Ключевое поведение

- **Ctrl+T / кнопка «+»** — Chrome открывает новую вкладку → `view.html` (toby) автоматически через `chrome_url_overrides.newtab`.
- **Сохранить текущую вкладку** — из popup (с выбором папки) или Ctrl+Shift+S. Сохранённые вкладки мгновенно появляются на всех открытых toby-страницах через `chrome.storage.onChanged`.
- **Поиск** — фильтрация по имени, заголовку и URL прямо на странице (клавиша `/` фокусирует поле).
- **Переименование** — двойной клик по имени карточки → inline input (Enter — сохранить, Esc — отмена).
- **Папки** — чипы папок в шапке (клик — фильтр, повторный клик / «Все» — сброс); «+ Папка» — модалка создания; ✎/✕ на чипе (hover) — переименовать / удалить (с confirm, вкладки папки уходят в «Все»).
- **Вложенные папки** — папки внутри папок (1 уровень: `parentId` у папки, у родительской папки parent не может быть). Чипы вложенных папок — с отступом и «↳». Фильтр по папке включает вкладки вложенных папок (рекурсивно). Дропдаун перемещения на карточке и селектор в popup показывают иерархию (отступ + «↳»). Удаление родительской папки: вложенные папки удаляются, все их вкладки перемещаются в «Все».
- **Drag & drop** — карточку можно перетащить на чип папки (включая «Все») — вкладка перемещается в него. Карточку можно перетащить на другую карточку — reorder: верхняя половина целевой карточки — вставить перед ней, нижняя — после (2px индикаторная линия на краю целевой карточки, цвет — `var(--ink)`); работает при любом фильтре (позиция считается по полному массиву 'blattam-tabs', folderId не меняется); дроп на себя — no-op, dragend без drop — без следов. Нативный HTML5 DnD, без внешних библиотек.
- **Массовое открытие** — чекбокс на карточке (или «☑ Выбрать» в шапке — все видимые) → плавающая панель внизу: «Открыть» создаёт вкладки (неактивные), «Сбросить» — снять. Клик по открытой вкладке или изменение storage сбрасывает выбор.
- **Клавиатурная навигация** — стрелки по карточкам (зациклено, в пределах текущего фильтра), Enter — открыть активную, Delete/Backspace — удалить (с подтверждением), Esc — сбросить поиск/фильтр папки/выбор/активную карточку (работает и из поля ввода). Активная карточка подсвечена монохромным чёрным контуром.
- **Горячая клавиша** — Ctrl+Shift+S (блок `commands` в manifest: `save-tab`, suggested key «Ctrl+Shift+S», описание «Сохранить текущую вкладку») — сохраняет текущую вкладку тем же путём, что popup (дедупликация по URL, folderId по умолчанию null); chrome:// URL пропускаются.
- **Фавикон на карточках** — при сохранении вкладки (popup «Сохранить» или Ctrl+Shift+S) общий save-путь в background.js захватывает `tabs.favIconUrl` и кладёт его полем `favIconUrl` в сохранённую вкладку (сам иконку не скачиваем — URL-адреса загружаются прямо в `<img>`). На карточке — маленький `<img class="tab-favicon">` (15×15, 1px-граница `var(--line)`, скругление 3px, `object-fit: contain`) перед именем; если `favIconUrl` отсутствует или картинка не загрузилась (onerror) — монохромный буквенный fallback-тайл с первой буквой домена (`var(--hover)`/`var(--text-muted)`, обе темы). Импорт: `favIconUrl` у вкладок сохраняется; экспорт: едет обычным полем; вкладки без фавикона рендерятся с fallback.
- **Удаление** — кликом по ✕ на карточке (с подтверждением).
- **Экспорт / импорт JSON** — «↓ Экспорт» / «↑ Импорт» в шапке: JSON с вкладками + папками (с parentId); импорт дедуплицирует по именам папок и по URL вкладок.

## Релиз (Chrome Web Store)

- **Иконки** — `icons/icon16.png`, `icons/icon48.png`, `icons/icon128.png`: чёрный квадрат с белым глифом браузерной вкладки (flat, монохром, читаемо на 16px). В manifest — верхнеуровневый блок `icons` (16/48/128) и `action.default_icon`.
- **Сборка zip** — `build_zip.py` (только stdlib; `python build_zip.py` из корня) собирает `dist/BlattamToby-v<версия>.zip` по строгому списку файлов расширения (manifest.json, background.js, popup.html, popup.js, view.html, view.js, theme.css, icons/*). Всё остальное (test_plugin.py, `__pycache__`, .pytest_cache, .git, *.md, dist/) исключено. Даты zip-элементов зафиксированы → сборка воспроизводима байт-в-байт. `dist/` в `.gitignore` (артефакт сборки, собирается заново).
- **Материалы магазина** — `store/DESCRIPTION.md` (короткое описание ≤132 символов для поля магазина + полное описание на русском и English version) и 3 PNG-макета в `store/` (~1280x800) — реальный view.html в headless Chromium с моком chrome API: светлая тема, тёмная тема, активный поиск. `store/` — часть дистрибутива (НЕ gitignore).

## Сообщения между компонентами

| Действие | Откуда → Куда | Описание |
|---|---|---|
| `save-current` | popup → background | Сохранить текущую активную вкладку |
| `add-tab` | popup → background | Создать запись вручную (имя + URL) |
| `open` / `delete` | popup/view → background | Открыть/удалить вкладку по индексу |
| `open-one` / `open-many` | view → background | Открыть одну / несколько вкладок (массово — неактивно) |
| `move-tab` / `rename-tab` | view → background | Переместить в папку / переименовать |
| `create-folder` / `delete-folder` / `rename-folder` | view/popup → background | CRUD папок |

**Автообновление view:** `chrome.storage.onChanged` — все открытые newtab-страницы реагируют на изменения в хранилище без сообщений.

## Загрузка и установка расширения

1. Открыть `chrome://extensions`.
2. Включить **«Режим разработчика»** (правый верхний угол).
3. Нажать **«Загрузить распакованное расширение»** → выбрать директорию проекта.

Разработчик перезагружает расширение после каждого изменения кода.

## Стили и UI

- **Vercel-моно-дизайн** (Geist, 1px-границы, монохром): фон `#fff`, карточки `#fff`, граница `#eaeaea`-класса (через box-shadow `0 0 0 1px var(--line)`), текст `#171717`, приглушённый `#666`, hover `#fafafa`. Единственный «акцент» — чернильное черное (`--ink`): черные кнопки («Открыть», «Сохранить вкладку»), активные чипы, клавиатурный фокус. Радусы 6–8px, тени только на hover. Плотность карточек всегда компактная (без переключателя размера).
- **Шрифт** — Geist (Google Fonts link в view.html/popup.html) + системный fallback `system-ui`; для URL, счётчиков и keycaps — Geist Mono.
- Дизайн-токены в `theme.css` (CSS-переменные на `:root`): фон, поверхность, текст, границы, чернило, тени, геометрия карточек, шрифты. view.html и popup.html подключают его через `<link rel="stylesheet" href="theme.css">` и внутри своих `<style>` используют только `var(--*)` — жёстких hex в разметочных стилях нет.
- **Тёмная тема** — кнопка-переключатель 🌙/☀️ в шапке view.html; состояние хранится в `chrome.storage.local` под ключом `blattam-theme` ('dark'/'light', по умолчанию светлая). view.js при инициализации читает сохранённую тему и ставит `document.documentElement.dataset.theme` **до первого рендера** (чтобы страница не мигала). Тёмные значения токенов — в `[data-theme="dark"]` в `theme.css` (строгий монохром: bg `#000`/`#0a0a0a`, граница `#333`, текст `#ededed`, приглушённый `#a1a1a1`; чернило — светлое `#ededed`). Остальные стили править не нужно — только `var(--*)`.
