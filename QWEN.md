# BlattamToby — расширение для управления сохранёнными вкладками

Браузерное расширение Chrome (Manifest V3), менеджер сохранённых вкладок, вдохновлённый toby.io / Taby. Заменяет страницу новой вкладки на свою — при Ctrl+T или клике по «+» в браузере открывается toby с сохранёнными вкладками.

## Архитектура

```
manifest.json          — Manifest V3, chrome_url_overrides.newtab → view.html
background.js          — Service worker, CRUD вкладок (ключ: "blattam-tabs")
popup.html / popup.js  — Popup: кнопка «Сохранить текущую вкладку» с подтверждением
view.html / view.js    — Страница новой вкладки (newtab override) со списком сохранённых вкладок
```

### Хранилище

Ключ `blattam-tabs`, элементы формата:
```js
{ name, url, title?, favIconUrl? }
```

## Ключевое поведение

- **Ctrl+T / кнопка «+»** — Chrome открывает новую вкладку → `view.html` (toby) автоматически через `chrome_url_overrides.newtab`.
- **Сохранить текущую вкладку** — из popup по имени вкладки. Сохранённые вкладки мгновенно появляются на всех открытых toby-страницах через `chrome.storage.onChanged`.
- **Поиск** — фильтрация по имени и заголовку прямо на странице.
- **Переименование** — двойной клик по имени карточки → inline input (Enter — сохранить, Esc — отмена).
- **Drag & drop** — карточку можно перетащить на чип папки (включая «Все») — вкладка переместится в неё. Нативный HTML5 DnD, без внешних библиотек.
- **Массовое открытие** — чекбокс на карточке (или «☑ Выбрать» в шапке — все видимые) → плавающая панель внизу: «Открыть» создаёт вкладки (неактивные), «Сбросить» — снять. Клик по открытой вкладке или изменение storage сбрасывают выбор.
- **Удаление** — кликом по ✕ на карточке (с подтверждением).

## Сообщения между компонентами

| Действие | Откуда → Куда | Описание |
|---|---|---|
| `save-current` | popup → background | Сохранить текущую активную вкладку |
| `add-tab` | popup → background | Создать запись вручную (имя + URL) |
| `open` / `delete` | popup/view → background | Открыть/удалить вкладку по индексу |

**Автообновление view:** `chrome.storage.onChanged` — все открытые newtab-страницы реагируют на изменения в хранилище без сообщений.

## Загрузка и установка расширения

1. Открыть `chrome://extensions`.
2. Включить **«Режим разработчика»** (правый верхний угол).
3. Нажать **«Загрузить распакованное расширение»** → выбрать директорию проекта.

Разработчик перезагружает расширение после каждого изменения кода.

## Стили и UI

- CSS встроен в HTML (inline styles), без внешних зависимостей.
- Используется `system-ui` для шрифта.
- Цветовая схема: основной `#3498db`, фон `#f5f7fa`.
