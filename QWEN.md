# BlattamToby — расширение для управления сохранёнными вкладками

Браузерное расширение Chrome (Manifest V3), менеджер сохранённых вкладок, вдохновлённый toby.io / Taby. Заменяет страницу новой вкладки на свою — при Ctrl+T или клике по «+» в браузере открывается toby с сохранёнными вкладками.

## Архитектура

```
manifest.json          — Manifest V3, chrome_url_overrides.newtab → view.html
background.js          — Service worker, CRUD вкладок (ключ: "blattam-tabs")
popup.html / popup.js  — Popup: кнопка «Сохранить текущую вкладку» с подтверждением
view.html / view.js    — Страница новой вкладки (newtab override) со списком сохранённых вкладок
theme.css              — дизайн-токены (CSS-переменные), общие для view и popup
icons/                 — иконки расширения: icon16.png / icon48.png / icon128.png
build_zip.py           — сборка dist/BlattamToby-v<версия>.zip для Chrome Web Store (только stdlib)
store/                 — материалы магазина: DESCRIPTION.md + screenshot-1..3.png
```

### Хранилище

Ключ `blattam-tabs`, элементы формата:
```js
{ name, url, title?, favIconUrl?, folderId?, tagIds?, id?, hasScreenshot?, archivedAt? }
```
`id` — id живой вкладки Chrome (ставится при сохранении через popup/hotkey), нужен для маппинга скриншотов; `hasScreenshot` — boolean, сам скриншот НЕ хранится в sync; `archivedAt` — timestamp (мс), ставится при закрытии браузерной вкладки с этим URL (архив закрытых вкладок, см. «Автосохранение при закрытии»); `folderId`/`tagIds` при архивации не трогаются.

Ключ `blattam-folders` — папки (категории), формат:
```js
{ id, name, parentId }  // parentId — null (корневая) или id родительской папки (вложенность 1 уровень)
```

Ключ `blattam-tags` — теги (цветовые метки), формат:
```js
{ id, name, color }  // color — 1..6 (палитра, токены --tag-1..6 в theme.css)
```

Ключ `blattam-screenshots` (`chrome.storage.local`) — скриншоты вкладок, формат:
```js
{ [tabId]: dataUrl }  // миниатюры ~160px в ширину (JPEG dataURL, downscaled on canvas)
```
Хранится в local, а не в sync: сырые скриншоты весят мегабайты, лимит sync — 100KB на элемент.

Ключ `blattam-card-size` (`chrome.storage.local`) — размер карточек: `'large'` (по умолчанию) / `'compact'`.

Ключ `blattam-theme` (`chrome.storage.local`) — тема: `'light'` (по умолчанию) / `'dark'`.

Ключ `blattam-sessions` (`chrome.storage.sync`) — сессии (именованные группы сохранённых вкладок), формат:
```js
{ id, name, createdAt, tabUrls: [url, ...] }
```
Сессия хранит набор URL сохранённых вкладок (не копии) — по ней фильтруется view.

Ключ `blattam-stats` (`chrome.storage.local`) — статистика открытий сохранённых вкладок (per-device, может расти — не sync):
```js
{ url: { opens, lastOpened } }
```
При каждой записи прорезивается до 500 URL по `lastOpened` (срезаются самые старые), чтобы не выйти за лимит local-хранилища.

## Ключевое поведение

- **Ctrl+T / кнопка «+»** — Chrome открывает новую вкладку → `view.html` (toby) автоматически через `chrome_url_overrides.newtab`.
- **Сохранить текущую вкладку** — из popup по имени вкладки. Сохранённые вкладки мгновенно появляются на всех открытых toby-страницах через `chrome.storage.onChanged`.
- **Поиск** — фильтрация по имени и заголовку прямо на странице.
- **Переименование** — двойной клик по имени карточки → inline input (Enter — сохранить, Esc — отмена).
- **Drag & drop** — карточку можно перетащить на чип папки (включая «Все») — вкладка переместится в неё. Нативный HTML5 DnD, без внешних библиотек.
- **Массовое открытие** — чекбокс на карточке (или «☑ Выбрать» в шапке — все видимые) → плавающая панель внизу: «Открыть» создаёт вкладки (неактивные), «Сбросить» — снять. Клик по открытой вкладке или изменение storage сбрасывает выбор.
- **Теги / цветовые метки** — ряд чипов тегов (рядом с чипами папок) с цветными точками из палитры (6 цветов, токены `--tag-1..6`); клик по чипу фильтрует карточки по тегу — одновременно с фильтром папок и поиском (повторный клик снимает фильтр). На карточке — цветные точки тегов вкладки в шапке; кнопка 🎨 открывает дропдаун-чекбоксы для мультиселекта тегов вкладки (аналог дропдауна папки, но несколько тегов сразу). Модалка «+ Тег» — название + выбор цвета из палитры. Удаление тега — ✕ на чипе (с подтверждением), tagIds у вкладок очищаются. Экспорт/импорт JSON включает теги (ключ `tags`).
- **Вложенные папки** — папки внутри папок (1 уровень: `parentId` у папки, у родительской папки parent не может быть). Чипы вложенных папок — с отступом и «↳». Фильтр по папке включает вкладки вложенных папок (рекурсивно). Дропдаун перемещения на карточке и селектор в popup показывают иерархию (отступ + «↳»). Удаление родительской папки: вложенные папки удаляются, все их вкладки перемещаются в «Все».
- **Клавиатурная навигация** — стрелки по карточкам (зациклено, в пределах текущего фильтра), Enter — открыть активную, Delete/Backspace — удалить (с подтверждением), Esc — сбросить поиск/фильтр папки/выбор/активную карточку (работает и из поля ввода). Активная карточка подсвечена.
- **Горячая клавиша** — Ctrl+Shift+S (блок `commands` в manifest: `save-tab`, suggested key «Ctrl+Shift+S», описание «Сохранить текущую вкладку») — сохраняет текущую вкладку тем же путём, что popup (дедупликация по URL, folderId по умолчанию null); chrome:// URL пропускаются.
- **Размер карточек** — кнопка ▦ «Крупные» / ▤ «Компактные» в шапке view: компактный режим — меньше карточки (больше колонок), плотнее отступы, меньше шрифт; состояние в `chrome.storage.local` (`blattam-card-size`, 'large'/'compact', по умолчанию 'large'), применяется до первого рендера (тот же паттерн, что тема — без мигания). Реализация: класс `compact-cards` на `document.body` + переопределение токенов размеров из `theme.css`. Esc (глобальный сброс) НЕ сбрасывает размер — это постоянная настройка.
- **Скриншоты вкладок** — при сохранении вкладки (popup «Сохранить» или Ctrl+Shift+S) `chrome.tabs.captureVisibleTab` снимает вкладку; dataURL даунскейлится до ~160px на offscreen `<canvas>` и хранится в `chrome.storage.local` под ключом `blattam-screenshots` как `{ tabId: dataUrl }` (НЕ в sync: сырые скриншоты весят мегабайты, лимит sync — 100KB). Вкладка хранит только `hasScreenshot: true` и `id` — импорт/экспорт остаётся лёгким. В view на карточке сверху появляется `<img>`-миниатюра (width 100%, object-fit cover, фиксированная высота, border-bottom) — скриншоты грузятся лениво (после первого рендера + перерисовка); без скриншота карточка как обычно. chrome:// и chrome-extension:// не снимаются; сбой capture (неактивное окно и т.п.) не ломает сохранение. Удаление вкладки (✕/Delete в view, `delete` в background) убирает её скриншот (view-путь — в view.js, background-путь — в background.js).
- **Автосохранение при закрытии (архив закрытых вкладок)** — `chrome.tabs.onRemoved` в background.js: закрыли браузерную вкладку и её URL есть среди сохранённых — на сохранённую вкладку с этим URL ставится `archivedAt` (timestamp, мс); `folderId`/`tagIds` не трогаются. Без дублей: если вкладка с этим URL уже в архиве — только обновляется `archivedAt`; если закрытый URL не сохранён — ничего не происходит. Обработчик события использует объект закрытой вкладки из параметра события (`url`/`title` уже там — `chrome.tabs.get` после удаления не работает). В view: архивные вкладки рендерятся приглушёнными (класс `archived`, токен `--archived-opacity` из `theme.css`), на карточке — маленькая кнопка «↩» (снимает `archivedAt` и пересохраняет вкладку). В шапке — чип «🗄 Архив» (стиль как у чипов папок, только токены) — фильтрует view на архив-только (toggle); Esc (глобальный сброс) тоже снимает фильтр. `archivedAt` — обычное поле вкладки: экспорт/импорт JSON уносит и восстанавливает его.
- **Сессии** — группировка сохранённых вкладок по именованным сессиям (время + контекст). Ключ `blattam-sessions` (`chrome.storage.sync`): массив `{ id, name, createdAt, tabUrls: [urls...] }`. Кнопка «📋 + Сессия» в шапке (рядом с папками/тегами): модалка (существующий паттерн модалок) — пользователь задаёт имя; если имя не введено, подставляется «Сессия 21.10» (ДД.ММ текущей даты) — можно изменить в модалке. По умолчанию сессия захватывает ВСЕ сейчас видимые вкладки (с учётом текущих фильтров). Отдельный ряд сессионных чипов (под чипами тегов, префикс «📋», выделенный стиль): клик по чипу — фильтр view на вкладки этой сессии (комбинируется с папкой/тегом/архивом/рекомендациями/поиском, повторный клик снимает); «+» на чипе (видна при наведении) — добавить сейчас видимые вкладки в сессию (без дублей); «✕» на чипе — удалить сессию (с confirm). Сессии в sync — видны на всех устройствах; обработчик `chrome.storage.onChanged` для `blattam-sessions` перечитывает чипы и перерисовывает (новый sync-ключ шлёт событие на всю sync-область, но обработчики читают свои ключи — продолжают работать).
- **Рекомендации (Частые / Избранные)** — на основе истории открытий. Ключ `blattam-stats` (`chrome.storage.local`, per-device, может расти — не sync): карта `{ url: { opens: N, lastOpened: timestamp } }`. `opens` инкрементится при каждом открытии сохранённой вкладки — все `chrome.tabs.create`, идущие из сохранённой вкладки, идут через один хелпер в background.js (`createTabFromSaved`: `open` по индексу, `open-one` из view, `open-many` массовое открытие). При каждой записи `blattam-stats` прорезивается до 500 URL (по свежести `lastOpened`). В view — два спец-чипа в ряду шапки (только токены): **«⭐ Частые»** — топ-20 по `opens`, только URL с `opens >= 2`; **«🕘 Избранные»** — топ-10 по `lastOpened` среди открытых за последние 7 дней. Клик — фильтрует view на этот набор (комбинируется с другими фильтрами); повторный клик — снимает. Смыслы фиксированы: Частые = самые открываемые (минимум 2), Избранные = недавно открываемые (окно 7 дней, топ-10).
- **Удаление** — кликом по ✕ на карточке (с подтверждением).

## Релиз (Chrome Web Store)

- **Иконки** — `icons/icon16.png`, `icons/icon48.png`, `icons/icon128.png`: скруглённый квадрат в акцентном синем `#3498db` с белым глифом браузерной вкладки (flat, читаемо на 16px). В manifest — верхнеуровневый блок `icons` (16/48/128) и `action.default_icon`; Chrome использует их в списке расширений и в тулбаре.
- **Сборка zip** — `build_zip.py` (только stdlib; `python build_zip.py` из корня) собирает `dist/BlattamToby-v<версия>.zip` по строгому списку файлов расширения (manifest.json, background.js, popup.html, popup.js, view.html, view.js, theme.css, icons/*). Всё остальное (test_plugin.py, `__pycache__`, .pytest_cache, .git, *.md, dist/) исключено. Даты zip-элементов зафиксированы → сборка воспроизводима байт-в-байт. `dist/` в `.gitignore` (артефакт сборки, собирается заново).
- **Материалы магазина** — `store/DESCRIPTION.md` (короткое описание ≤132 символов для поля магазина + полное описание на русском и English version) и `store/screenshot-1..3.png` (~1280x800) — реальный view.html в светлой и тёмной теме + компактный режим, снятые через headless Chromium с моком chrome API (тот же паттерн, что test_plugin.py). `store/` — часть дистрибутива (НЕ gitignore).

## Сообщения между компонентами

| Действие | Откуда → Куда | Описание |
|---|---|---|
| `save-current` | popup → background | Сохранить текущую активную вкладку |
| `add-tab` | popup → background | Создать запись вручную (имя + URL) |
| `open` / `delete` | popup/view → background | Открыть/удалить вкладку по индексу |

**Автообновление view:** `chrome.storage.onChanged` — все открытые newtab-страницы реагируют на изменения в хранилище без сообщений.

## Загрузка и установка расширения

1. Открыть `chrome://extensions`.
2. Включить **«Режим разработчика»** (правый верхний угол).
3. Нажать **«Загрузить распакованное расширение»** → выбрать директорию проекта.

Разработчик перезагружает расширение после каждого изменения кода.

## Стили и UI

- Дизайн-токены в `theme.css` (CSS-переменные на `:root`): палитра, текст, границы, акцент, тени. view.html и popup.html подключают его через `<link rel="stylesheet" href="theme.css">` и внутри своих `<style>` используют только `var(--*)` — жёстких hex в разметочных стилях нет.
- Шрифт `system-ui`. Светлая тема по умолчанию; акцент `#3498db` (`--accent`), фон `#f5f7fa` (`--bg`), клавиатурный фокус `#e67e22` (`--kbd`).
- **Тёмная тема** — кнопка-переключатель 🌙/☀️ в шапке view.html; состояние хранится в `chrome.storage.local` под ключом `blattam-theme` ('dark'/'light', по умолчанию светлая). view.js при инициализации читает сохранённую тему и ставит `document.documentElement.dataset.theme` **до первого рендера** (чтобы страница не мигала). Тёмные значения токенов — в `[data-theme="dark"]` в `theme.css` (переопределение всех переменных, у которых тёмный смысл; `--accent` слегка поднят, `--on-accent` и функциональные цвета не меняются). Остальные стили править не нужно — только `var(--*)`.
