# BlattamToby — расширение для управления сохранёнными вкладками

Браузерное расширение Chrome (Manifest V3), менеджер сохранённых вкладок, вдохновлённый toby.io / Taby. Заменяет страницу новой вкладки на свою — при Ctrl+T или клике по «+» в браузере открывается toby с сохранёнными вкладками.

## Архитектура

```
manifest.json          — Manifest V3, chrome_url_overrides.newtab → view.html
background.js          — Service worker: CRUD вкладок/пространств/групп, миграция legacy-папок
popup.html / popup.js  — Popup: «Сохранить вкладку» с выбором пространства
view.html / view.js    — Страница новой вкладки (newtab override): пространства, группы, карточки
theme.css              — дизайн-токены (CSS-переменные), общие для view и popup
icons/                 — иконки расширения: icon16.png / icon48.png / icon128.png
build_zip.py           — сборка dist/BlattamToby-v<версия>.zip для Chrome Web Store (только stdlib)
store/                 — материалы магазина: DESCRIPTION.md + 3 PNG-макета
```

### Хранилище

Ключ `blattam-tabs`, элементы формата:
```js
{ name, url, title?, favIconUrl?, comment?, spaceId (обязательно), groupId? }
```
`favIconUrl` — URL фавикона сайта (ставится при сохранении через popup/hotkey, если у вкладки он есть; data: URL тоже допустим; без него — поле отсутствует, в view отрендерится буквенный fallback). `groupId` — группа внутри пространства (отсутствует/null — вкладка вне групп). `comment` — свободный комментарий к вкладке: показывается внизу внутри карточки (моно, обрезается); пустой/отсутствующий — поле не ставится (из записи уходит сам ключ).

Ключ `blattam-spaces` — пространства (плоские, без вложенности):
```js
{ id, name }
```
Первое по умолчанию — «Мои вкладки». Дубли по имени (без учёта регистра) не создаются.

Ключ `blattam-groups` — сворачиваемые группы внутри пространств:
```js
{ id, name, spaceId, collapsed }
```
Группы плоские, живут в одном пространстве. Пустая группа рендерится с «0 вкладок». Группа, потерявшая последнюю вкладку, автоматически сворачивается (collapsed: true — шапка с «0 вкладок», без строки «Перетащите вкладку сюда»); свежесозданная или вручную развёрнутая пустая группа остаётся развёрнутой — её слот-заглушка — цель дропа.

Ключ `blattam-last-space` — последнее активное пространство: по умолчанию для save-пути (popup/горячая клавиша) и стартовое пространство view.

Ключ `blattam-folders` — **legacy**: потребляется только одноразовой миграцией (каждая папка любого уровня → отдельное пространство с тем же именем, вкладки переезжают folderId → spaceId, без папки → «Мои вкладки»). После миграции ключ удаляется.

Ключ `blattam-theme` (`chrome.storage.local`) — тема: `'light'` (по умолчанию) / `'dark'`.

Ключ `blattam-tabs` (список вкладок) — в **`chrome.storage.local`** (per-device, ~10 МБ — большие коллекции на 1000+ вкладок влезают; лимит sync 8 КБ/ключ ломал запись уже на ~20 вкладках). При загрузке — идемпотентная миграция: local пуст, а в sync непустой `blattam-tabs` → ключ копируется из sync в local и sync-ключ удаляется; local заполнен → только удаление stale-sync-ключа (local wins). Запускается и в background.js (до `loadTabs`/`saveTabs`), и в view.js (до первого рендера — без мигания). `blattam-spaces`, `blattam-groups`, `blattam-last-space` — в `chrome.storage.sync` (синк между устройствами; синк всей библиотеки — в будущем, вместе с фичей аккаунтов).

## Ключевое поведение

- **Ctrl+T / кнопка «+»** — Chrome открывает новую вкладку → `view.html` (toby) автоматически через `chrome_url_overrides.newtab`.
- **Сохранить текущую вкладку** — из popup (с выбором пространства) или Ctrl+Shift+S. Сохранённые вкладки появляются мгновенно на всех открытых toby-страницах через `chrome.storage.onChanged`.
- **Пространства** — чипы в шапке (клик — переключение, активное подсвечено чернилом; высота чипа 26px); «+ Пространство» — модалка создания (пустое имя → «Пространство N», дубль пропускается); кнопка в правом краю ряда пространств (после чипов — чипы рендерятся первыми, кнопка последним элементом ряда), бледный текстовый стиль (без рамки); ✎/✕ на чипе (hover) — переименовать / удалить (с confirm; вкладки удалённого пространства уходят в первое оставшееся, группы удаляются, `blattam-last-space` перенацелено). Чипы перетаскиваются на другие чипы — перестановка пространств, как drag карточек: захваченный чип исчезает из ряда (display:none), по ряду чипов за курсором идёт тёплая слот-заглушка `.space-ghost-slot` (высота чипа 26px, радиус чипа, фон `--ghost-bg` + пунктирный `--ghost-ring`) — единственный индикатор вставки (2px-линия на кромке цели убрана): левая половина целевого чипа — заглушка вставляется перед ним, правая — после; число элементов ряда при drag неизменно; дроп в любом месте ряда (зазор между чипами, отступы, кнопка «+ Пространство») ставит пространство в позицию заглушки (как у карточек — дроп в любом месте списка); no-op-guard: если порядок не изменился — запись в storage не идёт; порядок сохраняется в `blattam-spaces`; дроп на себя — no-op; активное пространство и `blattam-last-space` не меняются; ложный клик по чипу сразу после дропа не переключает пространство, настоящее нажатие — переключает
- **Группы** — сворачиваемые секции внутри пространства (клик по шапке — свернуть/развернуть, состояние в данных и переживает перерисовку); «+ Группа» — полноширинная пунктирная строка (40px, `1px dashed var(--dashed)`, hover `var(--hover)`/`var(--dashed-hover)`) в конце списка вкладок — во всех ветках рендера, включая полностью пустое пространство (пустое имя → «Группа N»); шапки групп перетаскиваются на другие шапки — reorder внутри активного пространства (верхняя половина цели — вставить перед, нижняя — after; 2px-индикаторная линия `var(--ink)` на кромке цели; порядок сохраняется в порядке `blattam-groups` — группы других пространств сохраняют относительный порядок, collapsed/члены остаются у группы, дроп на себя — no-op); счётчик групп в мета-строке больше не показывается; ✕ на шапке группы — удалить (вкладки остаются в пространстве); ✎ на шапке группы (hover-only, рядом с ✕) — инлайн-ренейм: имя шапки становится `<input>` с текущим именем (Enter/blur — сохранить, Esc — отмена, пустое имя — старое имя сохраняется; клик не сворачивает группу и не стартует drag; запись в `blattam-groups`, дубли имён допустимы); ☑ на шапке группы (hover-only, при полностью выбранной группе — заполнен чернилом и видим без hover) — выбрать/снять выбор ВСЕХ вкладок группы (независимо от сворачивания): все уже выбраны → снять, иначе → добавить. Переезд вкладки в группу — через ghost-slot: мишень — карточки группы (заглушка встаёт в слот группы, place-tab задаёт groupId); шапка группы принимает карточку, когда у группы НЕТ ВИДИМЫХ карточек (пустая 0 вкладок, свёрнутая, единственная карточка перетаскивается): дроп на шапку = place-tab anchorIndex null (в конец списка) + groupId группы, карточка своей группы — NO-OP, армед-вид — тёплый тон (--ghost-bg/--ghost-ring); шапка группы С видимыми карточками — no-op, без подсветки; пустая развёрнутая группа рендерит под шапкой полноширинный пунктирный слот-заглушку «Перетащите вкладку сюда» (.group-empty-slot, высота карточки 74px, 1px dashed --dashed, --card-radius, --text-faint, --font-mono) — он тоже drop-цель; перенос в/из/внутри группы — только через ghost-slot; клик по шапке сразу после дропа (карточка/шапка — некоторые браузеры генерируют клик после drop) НЕ переключает сворачивание группы (окно 500 мс от последнего dragend) — дроп на свёрнутую группу уезжает в неё, не раскрывая. ☑ у строки «Без группы» (hover, аналог ☑ шапки группы) — выбрать/снять ВСЕ негрупповые вкладки пространства (полный набор, независимо от поиска — скрытые фильтром тоже): все выделены → заполнен чернилом (виден без hover), повторный клик — снять всех.
- **DnD: post-drop клик не раскрывает группу** — дроп карточки на шапку свёрнутой/пустой группы уносит её в группу; ложный `click`, который браузер генерирует после drop, не сворачивает/раскрывает группу — даже когда перерисовка медленная (большая коллекция, соседние группы раскрыты) и клик приходит за 500ms-окном после `dragend` (one-shot флаг `pendingGbarClickAfterDrag`, вооружается на dragstart карточки и на drop по шапке — клик гасится, когда приходит и ДО dragend, и после; сбрасывается новым `mousedown` — реальные клики не глотаются; дроп по шапке также снимает тёплую заглушку ghost-slot, а отложенная заглушка не вставляется для отсоединённой карточки).
- **Переезд между пространствами** — drag&drop карточки на чип пространства (groupId очищается — между пространствами группы не ездят).
- **Поиск** — фильтрация по имени, заголовку и URL прямо на странице — поле наверху левой рейки (полная ширина рейки; ≤760px — скрыто, иконная рейка); клавиша `/` фокусирует поле. URL на карточке не отображается, но ищется. «Ничего не найдено» показывается только при активном поиске — сворачивание групп (карточек нет, но поиска нет) его больше не триггерит.
- **Карточка вкладки** — 74px высотой (высота без изменений; имя вкладки СВЕРХУ карточки, нижняя зона зарезервирована под будущий контент): ширина карточки -20% к прежней — сетка `--card-min` 141px (было 176px; единственный регулятор ширины: `repeat(auto-fill, minmax(var(--card-min), 1fr))` — в ряд влезает больше карточек), имя — 11.5px (`--card-name-size` — имя и инлайн-поле rename), цвет имени — токен `--card-name`: светлая тема — как `--text`, тёмная тема — ЧУТЬ ТУСКЛЕЕ (`#b5ada6` против `--text: #f5f2ee` — ближе к `--text-muted`), комментарий внизу карточки — 9px моно (было 10px); фавикон 15×15 + имя (без строки URL, без дропдауна). Фон карточки `--card-bg` — чуть контрастнее фона страницы (обе темы), 1px-граница. Клик — открыть, двойной клик по имени — inline rename (Enter — сохранить, Esc — отмена), ✕ — удалить (с confirm), чекбокс — выбор: при hover или в выбранном состоянии чекбокс заменяет фавикон (img и буквенный fallback) на месте — 15×15-слот фавикона, имя не сдвигается; на выбранной карточке чекбокс виден и без hover, после unhover у невыбранной карточки возвращается фавикон; клик по нему выбирает/снимает карточку (панель «N выбрано» обновляется). Длинное имя переносится на 2-ю строку (`.tab-name`: `white-space: normal`, `display: -webkit-box`, `-webkit-line-clamp: 2`, `overflow: hidden`), при переполнении обрезается многоточием в конце 2-й строки; короткое имя — одна строка; `.cname` — `align-items: flex-start` + `margin-top` у фавикона, так что фавикон стоит на первой строке имени; карточка остаётся ровно 74px и ничего не выходит за её границы (URL-строки нет, комментарий — одна строка внизу).
- **Редактирование вкладки (имя / адрес / комментарий)** — ✎ на карточке (hover-only, снизу-справа) открывает модалку по центру СРАЗУ — окно вертикальное (выше, чем шире), крупнее общей `.modal` (min-width 300px, поля 14px, поля/заголовки шире отступами), тон текста полей — токен `--card-name` (тот же тон, что у имени вкладки); скоуп только `#edit-tab-modal` — модалка пространств прежняя; промежуточное меню «Изменить» убрано полностью (нет ни JS-слоя меню, ни CSS `.tab-card-menu`) — с затемнённым фоном: поля имя/адрес/комментарий предзаполнены текущими значениями; Enter — сохранить, Esc / «Отмена» — закрыть; клик по затемнённому фону НЕ закрывает модалку (выделение текста в поле уносит указатель за окно — форма не схлопывается, значения в полях сохраняются). Пустое имя или адрес — старое значение сохраняется, пустой комментарий — комментарий очищается (ключ `comment` удаляется из записи). Сохранение шлёт `update-tab` в background; комментарий отображается внизу внутри карточки (моно, обрезается). Клик по ✎ не открывает вкладку и не стартует drag.

- **Drag & drop (reorder)** — toby-style: забрали карточку — она исчезает из слота (на её месте — заглушка ghost-slot, см. ниже); за курсором следует нативный drag-образ браузера (клон-призрака нет); ЕДИНСТВЕННЫЙ индикатор вставки — сама заглушка (2px-линия `var(--ink)` из перетаскивания карточек убрана). Работает при любом фильтре (позиция считается по якорям в полном массиве 'blattam-tabs'); дроп в тот же слот и ту же группу — no-op, dragend без drop — карточка возвращается в слот и без следов. На чипе пространства преимущество его семантики (в пространство); дроп карточки на шапку группы — no-op, если у группы есть видимые карточки; шапка пустой/свёрнутой группы и слот-заглушка пустой группы принимают карточку (заглушка над ними морозится, над слотом и армед-шапкой не бегает). Нативный HTML5 DnD, без внешних библиотек.
- **Drag & drop (reorder): ghost-slot (заглушка слота)** — при захвате карточки на её месте в сетке появляется ghost-заглушка того же размера и скругления (тёплый тон: фон `var(--ghost-bg)`, пунктирная граница `var(--ghost-ring)`; пустая, не draggable, прозрачная для курсора — `pointer-events:none`); заглушка следует за мышью в потенциальный слот вставки с учётом секций (начало/середина/конец группы, конец списка — на границе секций по позиции курсора относительно середины шапки группы: выше середины — конец предыдущей группы, ниже — начало текущей; заглушка якорится ПОСЛЕДНЕЙ карточкой предыдущей секции (никогда «перед» шапкой следующей: при прогоне свёрнутых групп между секциями заглушка не встаёт в пространство низкой свёрнутой группы — она не «раскрывается» с призрачной вкладкой); соседние карточки сдвигаются естественным reflow сетки), нативный drag-образ браузера следует за курсором (клон-призрака нет); при отпускании вкладка заменяет заглушку и встаёт в позицию её слота в полном 'blattam-tabs', а если заглушка в другой группе — вкладка переезжает в ту группу (groupId обновляется; негрупповая секция — groupId становится null); дроп на чип пространства — move-поведение без изменений; дроп на шапку группы с видимыми карточками — no-op; на шапку пустой/свёрнутой группы и на слот-заглушку пустой группы («Перетащите вкладку сюда») — вкладка в группу (place-tab, anchorIndex null — в конец списка; своя группа — no-op), над чипом пространства заглушка замирает (над шапкой/слотом — прячется целиком, см. «Drag-layout» ниже); заглушка убирается на dragend; drag без drop — карточка возвращается в свой слот, заглушка убирается, storage не тронут; перерисовка (storage.onChanged) во время drag — заглушка убирается аккуратно. Row-keeper: пока ghost-slot в исходной секции (дома или где-нибудь в ней), слоты секции занимают K-1 видимые карточки + заглушка — keeper в DOM отсутствует; когда заглушка уходит в другую секцию, невидимый плейсхолдер (`.tab-row-keeper`, размер карточки, opacity:0/pointer-events:none) подключается в КОНЦЕ исходной секции (после её последней видимой карточки; секция без видимых карточек — за её `.gbar`, негрупповая — перед «+ Группа»): число строк секции не меняется, список под ней не сдвигается (быстрый драг последней вкладки последней строки), а карточки закрывают высвобожденный слот без «дырки»; на dragend keeper убирается до восстановления карточки.
- **Drag-layout: рефлоу слота и заглушка скрыта ЦЕЛИКОМ над шапкой/слотом** — при захвате карточки и уходе заглушки от её слота соседние карточки ЗАКРЫВАЮТ высвобожденный слот естественным reflow сетки (пустой «дыры» на месте карточки нет); число строк исходной секции при этом фиксировано: его держит сама заглушка (пока ghost в секции) или невидимый row-keeper в конце секции (ghost в другой) — группы/вкладки под секцией не сдвигаются во время быстрого драга. Над шапкой ЛЮБОЙ группы (`.gbar` — развёрнутую, свёрнутую или пустую) и над слотом пустой группы (`.group-empty-slot`) заглушка прячется ЦЕЛИКОМ (`display:none` — её ячейка сетки освобождается: ни «тёплая» заглушка на старом месте, ни «дырки» — сетка перетекает), а невидимый row-keeper держит число строк исходной секции; заглушка остаётся в DOM и ВЕРНУЕТСЯ (display:''), когда курсор снова попадает в список (честный слот вставки). Полоса над шапкой (не сама шапка) — заглушка видна в хвосте исходной секции (честная позиция: дроп туда — в конец этой секции). Над чипом пространства заглушка, как и раньше, замирает. Семантика дропа не меняется: дроп в полосе — в конец предыдущей секции (slotAnchor), дроп на шапку пустой/свёрнутой группы — вкладка в группу (place-tab, anchorIndex null), группа остаётся свёрнутой (post-drop-клик подавлен), дроп на шапку с видимыми карточками — no-op.
- **Drag: единственный вкладка/вкладка «одна в группе» — домашний слот, дроп домой no-op** — когда в группе ровно одна вкладка (или единственная негрупповая), во время драга секция читается «пустой» (карточка скрыта) и геометрия прыгала через её полосу в соседнюю секцию: в момент захвата заглушка уезжала в соседнюю группу, а дроп домой менял группу/позицию — вкладку было невозможно вернуть на место. Теперь: пока курсор в полосе исходной секции (от низа её шапки до верха шапки следующей), заглушка остаётся в слоте схваченной карточки (домой, видима, не уезжает), а вкладку «несёт» нативный drag-образ браузера; дроп домой — точный no-op (позиция в 'blattam-tabs' и groupId не меняются). Механизм (view.js): `slotIsSourceHome(clientY)` в `slotAnchor` (домашний якорь `{el: dragSourceCardEl, side:'after'}`) + guard в `placeCardToSlot` (якорь — сама исходная карточка, сторона «после» → no-op). Шапка/слот СВОЕЙ группы, multi-tab-секции и дроп в другую группу — без изменений (TestOnlyTabHomeDrop).
- **Перенос выделенного батча** — перетащил карточку, входящую в выделение (чекбоксы, >1 вкладки), — уезжают ВСЕ выделенные вкладки: в рендере — как перенос одной вкладки (скрывается только захваченная карточка, заглушка одна, клон-призрака нет); батч встаёт блоком на позицию слота в исходном порядке вкладок (`place-tabs` в background: вырезка из полного массива 'blattam-tabs', вставка перед/после якорной вкладки или в конец; группа — группа целевой секции, пространство не меняется); на шапку/слот пустой/свёрнутой группы — батч целиком в группу (если хотя бы одна вкладка не там), на чип пространства — каждая вкладка батча переезжает в пространство (группы очищаются); если порядок и группы не меняются (якорь — член батча) — no-op, сообщение не шлётся; не-выделенная карточка уезжает одна (place-tab).
- **Массовое открытие** — чекбокс на карточке (кнопка «Выбрать»-select-all из мета-строки удалена) → плавающая панель внизу: «Открыть» открывает вкладки (неактивные), «Сбросить» — снять, «✕ Удалить» — массовое удаление выделенных: один confirm («Удалить N вкладку/вкладки/вкладок?» — правильные русские формы), на OK — все выбранные вкладки удаляются одной записью в storage, выбор снимается (пустой выбор — no-op, отмена — без изменений). Клик по открытой вкладке или изменение storage сбрасывает выбор. Выбранная карточка — темнее и бордовее: фон `var(--selected-bg)` (токен в обеих темах: светлая — `#efe8e9`, тёмная — `#2e2325` — темнее карточки, с бордовым оттенком) + деликатное бордовое 1px-кольцо `var(--selected-ring)` (светлая — `rgba(107, 16, 32, 0.25)`, тёмная — `rgba(222, 120, 138, 0.30)`) — заметнее обычной границы `--line`, но мягче сплошного чернила; чекбокс выбора — контурный (не сплошное чернило): фон `var(--surface)` + 1px-контур и галочка в бордовом `var(--selected-check)` (светлая — `rgba(107, 16, 32, 0.90)`, тёмная — `rgba(230, 145, 160, 0.95)`) — менее бросается в глаза.
- **Клавиатурная навигация** — стрелки по карточкам (зациклено, в пределах текущего фильтра; ↓/→ от ничего — первая, ↑/← от ничего — последняя), Enter — открыть активную, Delete/Backspace — удалить (с подтверждением), Esc — сбросить поиск/выбор/активную карточку (работает и из поля ввода). Активная карточка подсвечена монохромным контуром.
- **Горячая клавиша** — Ctrl+Shift+S (блок `commands` в manifest: `save-tab`, suggested key «Ctrl+Shift+S», description «Save current tab») — сохраняет текущую вкладку так же, как popup: в пространство по умолчанию (`blattam-last-space` → первое → «Мои вкладки»); дедупликация по URL + space; chrome:// URL пропускаются.
- **Фавикон на карточках** — общий save-путь в background.js захватывает `tabs.favIconUrl` и кладёт его полем `favIconUrl` в сохранённую вкладку (саму иконку не скачиваем — URL-адрес загружается прямо в `<img>`). На карточке — маленький `<img class="tab-favicon">` (15×15, 1px-граница `var(--line)`, скругление 3px, `object-fit: contain`) перед именем; если `favIconUrl` отсутствует или картинка не загрузилась (onerror) — монохромный буквенный fallback-тайл с первой буквой домена (`var(--hover)`/`var(--text-muted)`, обе темы). Импорт: `favIconUrl` у вкладок сохраняется; экспорт: едет обычным полем; вкладки без фавикона рендерятся с fallback.
- **Удаление** — клик по ✕ на карточке (с подтверждением).
- **Экспорт / импорт JSON** — «↓ Экспорт» / «↑ Импорт» в шапке: JSON с вкладками + пространства + группы; импорт дедуплицирует пространства/группы по имени и вкладки по URL; файлы legacy-формата (с `folders`) мигрируются по тем же правилам, что и storage.

## Сообщения между компонентами

| Действие | Откуда → Куда | Описание |
|---|---|---|
| `save-current` | popup/hotkey → background | Сохранить текущую активную вкладку (spaceId → по умолчанию) |
| `add-tab` | view/popup → background | Создать запись вручную (имя + URL) |
| `open` / `delete` | popup/view → background | Открыть/удалить вкладку по индексу |
| `open-one` / `open-many` | view → background | Открыть одну / несколько вкладок (пачкой — без активации) |
| `move-tab` | view → background | Перемещение: spaceId (в другое пространство, groupId очищается) и/или groupId (null — «Без группы») |
| `rename-tab` / `reorder-tab` | view → background | Переименование / reorder |
| `update-tab` | view → background | Редактирование вкладки: имя/адрес/комментарий (пустые имя/адрес → старые значения, пустой комментарий → удалить ключ) |
| `place-tab` | view → background | Дроп вкладки в позицию ghost-слота: позиция по якорю (перед/после вкладки; конец секции — после последней вкладки этой секции) + groupId секции заглушки (null — «Без группы»); тот же слот и та же группа — no-op; `anchorIndex: null` — в конец списка (дроп на шапку/слот пустой или свёрнутой группы) |
| `create-space` / `delete-space` / `rename-space` | view/popup → background | CRUD пространств |
| `create-group` / `delete-group` | view → background | CRUD групп (удаление: вкладки остаются в пространстве) |

**Автообновление view/popup:** `chrome.storage.onChanged` — все открытые newtab-страницы и popup реагируют на изменения storage без сообщений (popup дополнительно синхронизирует выбранное пространство с `blattam-last-space` и подсвечивает только что созданное пространство).

## Загрузка и установка расширения

1. Открыть `chrome://extensions`.
2. Включить **«Режим разработчика»** (правый верхний угол).
3. Нажать **«Load unpacked extension»** (Загрузить распакованное расширение) → выбрать директорию проекта.

Разработчик перезагружает расширение после каждого изменения кода.

## Стили и UI

- **Vercel-моно-дизайн** (Geist, 1px-границы, монохром): фон `#fff`, карточки `#f5f5f5` (`--card-bg`, чуть контрастнее фона страницы), шапка/модалки/шапки групп `#fff` (`--surface`), 1px-границы (через box-shadow `0 0 0 1px var(--line)`), текст `#171717`, приглушённый `#666`, hover `#fafafa`. Единственный «акцент» — чернильное чёрное (`--ink`): чёрные кнопки («Открыть», «Сохранить вкладку»), активные чипы, клавиатурный фокус, подсветка drop-over. Радиусы 6–8px, тени только на hover. Плотность карточек всегда компактная (без переключателя размера).
- **Шрифт** — Geist (Google Fonts-ссылка в view.html/popup.html) + системный fallback `system-ui`; для счётчиков и keycaps — Geist Mono.
- **Дизайн-токены** — в `theme.css` (CSS-переменные на `:root`): фоны, поверхности, текст, границы, чернило, тени, геометрия карточек, шрифты. view.html и popup.html включают его через `<link rel="stylesheet" href="theme.css">` и используют только `var(--*)` в своих `<style>`-блоках — без захардкоженных hex в стилях разметки.
- **Тёмная тема** — toggle-кнопка 🌙/☀️ в шапке view.html; состояние хранится в `chrome.storage.local` под ключом `blattam-theme` ('dark'/'light', по умолчанию светлая). view.js читает сохранённую тему при init и ставит `document.documentElement.dataset.theme` **до первого рендера** (страница не мигает). Тёмные значения токенов — в `[data-theme="dark"]` в `theme.css` (светлее и теплее: нейтрально-тёплая приглушённая палитра с повышенным контрастом, не «чёрное на чёрном» — bg `#1f1c1b`, поверхности `#2a2624`, карточки `#36312d`, граница `rgba(255,255,255,.10)`, текст `#f5f2ee`, приглушённый `#a8a09a`; чернило — светлое `#f5f2ee`). Остальные стили править не нужно — только `var(--*)`.
- **Тёплый акцент: заглушка перетаскивания** — при перетаскивании карточки оригинал исчезает из слота; в сетке единственный индикатор — тёплая пустая заглушка (`.tab-ghost-slot`, размер карточки: фон `var(--ghost-bg)` + 1px пунктирный контур `var(--ghost-ring)`) — стоит в слоте карточки и ходит за курсором к позиции вставки, дроп ставит карточку на её место. Клон-призрака нет: за курсором следует нативный drag-образ браузера. Токены `--ghost-bg`/`--ghost-ring` в обеих темах `theme.css` (light `#fbe3b6`/`#d99a4e`, dark `#4c3c22`/`#d7a24d`) — в `<style>` только `var(--*)`, без hex.
- **Шапка группы «Штрих»** — `.gbar`: полноширинная строка 26px БЕЗ заливки: 1px-линия сверху — оверлей `::before` из `--gbar-top-line` (светлая — сплошная `--line2`, тёмная — градиент, тускнеет к краям), chevron `--text-faint`, имя 12px/500 `--text-soft`, mono-счётчик `--text-faint`; hover — лёгкий фон `--gbar-hover` (светлая — `--hover`, тёмная — едва заметный) + контролы (☑ ✎ ✕); клик — сворачивание группы (счётчик остаётся, состояние в данных).
- **Тёмная тема: тонировка шапки группы и имени вкладки** — тёмная тема тише: имя вкладки `--card-name` тёмная — #b5ada6 (тусклее, ближе к --text-muted; светлая — #171717, без изменений); 1px-линия над шапкой группы (`.gbar`) — не border-top, а оверлей `.gbar::before` (absolute, top, 1px, layout-neutral) с токеном `--gbar-top-line`: светлая — `var(--line2)` (сплошная, без изменений), тёмная — градиент, тускнеет к краям (центр по яркости прежнего --line2); hover шапки группы — токен `--gbar-hover`: светлая — `var(--hover)`, тёмная — `rgba(255, 255, 255, 0.05)` (едва заметный). Во время reorder индикаторы `.drop-before`/`.drop-after` (сильнее по специфичности) перекрывают линию.
- **Newtab: 3-колонка** — `.workspace`: 220px рейка (поиск наверху — полная ширина рейки, ≤760px — скрыт; Тема/Экспорт/Импорт/Настройки — hover-reveal-строки, аккаунт-карта внизу; eyebrow «Меню» убран) / центр (in-column header: wordmark только, без кнопок; мета-строка — #meta-label + #meta-count, кнопка «Выбрать» удалена) / 190px рейка-плейсхолдер вкладок браузера (watermark «ВКЛАДКИ БРАУЗЕРА» + ghost-заглушки). Колонки разделены тоном: рейки залиты `--rail-bg` (light #f4f2f0 / dark #292523), без линий/теней; ≤760px — иконная рейка 60px, правая скрыта.
