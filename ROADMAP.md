---

## 🚀 Фичи для реализации

### Быстрые (1 коммит)

- [x] **Детект дублей** — не сохранять одинаковый URL дважды; проверять перед push в массив (`tabs.some(t => t.url === ...)`)
- [ ] **Редактирование имени** — двойной клик по названию карточки → inline input для переименования
- [x] **chrome.storage.sync вместо local** — синхронизация вкладок между устройствами Chrome (данные переживают переустановку)

### Структура и организация

- [ ] **Папки / категории** — группировать вкладки (Работа, Личное, Чтение...). Киллер-фича. Данные: `{ folderId, folderName, tabs[] }`
- [ ] **Drag & drop** — перетаскивание вкладок между папками и перестановка порядка (SortableJS или нативный DnD API)
- [ ] **Теги / цветовые метки** — цветные точки на карточках для быстрой навигации

### UX и навигация

- [ ] **Клавиатурная навигация по view** — стрелки по сетке, Enter → открыть, Delete → удалить, Esc → сброс фокуса
- [ ] **Поиск по URL/домену** — сейчас ищется только по имени и title
- [ ] **Массовое открытие** — чекбоксы на карточках + кнопка «Открыть выбранные»

### Умные фичи

- [ ] **Автосохранение при закрытии** — `chrome.runtime.onSuspend`: сохранять все открытые вкладки в папку «Сессия N»
- [x] **Импорт / Экспорт JSON** — бэкап и перенос между профилями браузера (кнопки в header view, детект дублей при импорте)
- [ ] **Последние закрытые** — `chrome.tabs.onRemoved` → автоматически сохранять закрытые вкладки в архив
