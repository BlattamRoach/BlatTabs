## 🚀 Фичи для реализации

### Быстрые (1 коммит)

- [x] **Редактирование имени** — двойной клик по названию карточки → inline input (Enter — сохранить, Esc — отмена, одиночный клик всё ещё открывает вкладку)
- [x] **Поиск по URL/домену** — matchFilter ищет по name + title + url (был реализован ранее, отмечено)

### Структура и организация

- [x] **Drag & drop** — перетаскивание карточки на чип папки (нативный HTML5 DnD, без библиотек; «Все» тоже принимает)
- [ ] **Теги / цветовые метки** — цветные точки на карточках для быстрой навигации
- [ ] **Вложенные папки** — папки внутри папок

### UX и навигация

- [x] **Клавиатурная навигация по view** — стрелки (↑↓←→) по карточкам (зациклено, учитывают фильтр папки и поиск), Enter → открыть, Delete/Backspace → удалить (с подтверждением), Esc → сброс (поиск, фильтр папки, выбор, активная карточка). Активная карточка подсвечена оранжевым контуром. Не перехватывает, пока фокус в поле ввода или открыта модалка; Esc из поля поиска тоже сбрасывает всё
- [x] **Массовое открытие** — чекбоксы на карточках + плавающая панель «N выбрано / Открыть / Сбросить»; «☑ Выбрать» в шапке выбирает/снимает все видимые; клик по открытой вкладке снимает выбор; изменение storage сбрасывает выбор; вкладки открываются неактивными
- [ ] **Горячие клавиши** — Ctrl+Shift+S для сохранения текущей вкладки

### Умные фичи

- [ ] **Автосохранение при закрытии** — `chrome.tabs.onRemoved` → архив закрытых вкладок
- [ ] **Сессии** — группировка вкладок по сессиям (время + контекст)
- [ ] **Рекомендации** — "Часто открываемые", "Избранные" на основе истории

## 🎨 Дизайн

- [x] **Дизайн-токены** — общий `theme.css` с CSS-переменными (палитра, текст, границы, акцент, тени). view.html + popup.html используют только `var(--*)`, в `<style>` не осталось жёстких hex. Тёмная тема = переопределение переменных в `[data-theme="dark"]` (без перебора). Визуальный дифф нулевой — подтверждено пиксель-в-пиксель до/после
- [x] Тёмная тема (toggle в header) — кнопка 🌙/☀️ в шапке view.html; состояние в `chrome.storage.local` под ключом `blattam-theme` ('dark'/'light', по умолчанию светлая); тема применяется до первого рендера (без мигания)
- [ ] Адаптивные размеры карточек (крупный / компактный режим)
- [ ] Скриншоты вкладок на карточках (`chrome.tabs.captureVisibleTab`)
