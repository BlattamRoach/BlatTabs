## 🚀 Фичи для реализации

### Быстрые (1 коммит)

- [ ] **Редактирование имени** — двойной клик по названию карточки → inline input
- [ ] **Поиск по URL/домену** — сейчас ищется по name + title, добавить url в фильтр

### Структура и организация

- [ ] **Drag & drop** — перетаскивание вкладок между папками (SortableJS / нативный DnD)
- [ ] **Теги / цветовые метки** — цветные точки на карточках для быстрой навигации
- [ ] **Вложенные папки** — папки внутри папок

### UX и навигация

- [ ] **Клавиатурная навигация по view** — стрелки, Enter → открыть, Delete → удалить, Esc → сброс
- [ ] **Массовое открытие** — чекбоксы на карточках + кнопка «Открыть выбранные»
- [ ] **Горячие клавиши** — Ctrl+Shift+S для сохранения текущей вкладки

### Умные фичи

- [ ] **Автосохранение при закрытии** — `chrome.tabs.onRemoved` → архив закрытых вкладок
- [ ] **Сессии** — группировка вкладок по сессиям (время + контекст)
- [ ] **Рекомендации** — "Часто открываемые", "Избранные" на основе истории
