## 🚀 Фичи для реализации

### Быстрые (1 коммит)

- [x] **Редактирование имени** — двойной клик по названию карточки → inline input (Enter — сохранить, Esc — отмена, одиночный клик всё ещё открывает вкладку)
- [x] **Поиск по URL/домену** — matchFilter ищет по name + title + url (был реализован ранее, отмечено)

### Структура и организация

- [x] **Drag & drop** — перетаскивание карточки на чип папки (нативный HTML5 DnD, без библиотек; «Все» тоже принимает)
- [x] **Reorder карточек (drag & drop)** — перетаскивание карточки на другую карточку меняет порядок в 'blattam-tabs': верхняя половина цели — вставить перед, нижняя — после (2px индикаторная линия var(--ink) на верхней/нижней кромке); работает в любом фильтре (позиция считается по полному массиву), folderId не трогается; на себя — no-op, dragend без drop — без следов (нативный HTML5 DnD, без библиотек)
- [ ] **Теги / цветовые метки** — ~~цветовые метки~~ — **убрано из проекта (решение пользователя)**: ключ `blattam-tags`, CRUD тегов, `tagIds` у вкладок, чипы/модалка/точки/🎨-дропдаун, фильтр по тегам, теги в экспорте/импорте — удалено без остатка
- [x] **Вложенные папки** — папки внутри папок (1 уровень: `parentId` у папки); чипы вложенных папок — с отступом и «↳»; фильтр папки включает вкладки вложенных папок рекурсивно; дропдаун перемещения и селектор popup показывают иерархию; удаление родительской папки переносит вложенные папки и все их вкладки в «Все»

### UX и навигация

- [x] **Клавиатурная навигация по view** — стрелки (↑↓←→) по карточкам (зациклено, учитывают фильтр папки и поиск), Enter → открыть, Delete/Backspace → удалить (с подтверждением), Esc → сброс (поиск, фильтр папки, выбор, активная карточка). Активная карточка подсвечена оранжевым контуром. Не перехватывает, пока фокус в поле ввода или открыта модалка; Esc из поля поиска тоже сбрасывает всё
- [x] **Массовое открытие** — чекбоксы на карточках + плавающая панель «N выбрано / Открыть / Сбросить»; «☑ Выбрать» в шапке выбирает/снимает все видимые; клик по открытой вкладке снимает выбор; изменение storage сбрасывает выбор; вкладки открываются неактивными
- [x] **Горячие клавиши** — Ctrl+Shift+S (manifest `commands.save-tab`, suggested key «Ctrl+Shift+S», description по-русски) — сохранение текущей вкладки; background.js слушает `chrome.commands.onCommand`, chrome:// URL пропускаются (тот же save-current путь: дедупликация по URL, folderId по умолчанию null)
- [x] **Фавикон на карточках (SITE FAVICON)** — при сохранении вкладки (popup + hotkey, общий save-путь) `tabs.favIconUrl` захватывается и хранится полем `favIconUrl` у сохранённой вкладки (только URL, не скачиваем; data: URL тоже ок; пустой/отсутствующий — поле не ставится, sync-объект остаётся лёгким). На карточке — маленький `<img class="tab-favicon">` (15px, 1px-граница, скругление 3px) перед именем; если фавикона нет или он не загрузился (onerror) — монохромный буквенный fallback-тайл (первая буква домена, `var(--hover)`/`var(--text-muted)`/1px `var(--line)`) — в обеих темах. Импорт: `favIconUrl` у вкладок сохраняется; экспорт: едет обычным полем
