## 🚀 Фичи для реализации

### Быстрые (1 коммит)

- [x] **Редактирование имени** — двойной клик по названию карточки → inline input (Enter — сохранить, Esc — отмена, одиночный клик всё ещё открывает вкладку)
- [x] **Поиск по URL/домену** — matchFilter ищет по name + title + url (был реализован ранее, отмечено)

### Структура и организация

- [x] **Drag & drop** — перетаскивание карточки на чип папки (нативный HTML5 DnD, без библиотек; «Все» тоже принимает)
- [x] **Теги / цветовые метки** — палитра из 6 цветов (токены `--tag-1..6`), чипы тегов с фильтром (одновременно с папками и поиском), цветные точки на карточках, дропдаун-чекбоксы для мультиселекта тегов вкладки (🎨), модалка создания тега (название + цвет), удаление тега с confirm (tagIds у вкладок очищаются), экспорт/импорт включает теги (ключ `tags`)
- [x] **Вложенные папки** — папки внутри папок (1 уровень: `parentId` у папки); чипы вложенных папок — с отступом и «↳»; фильтр папки включает вкладки вложенных папок рекурсивно; дропдаун перемещения и селектор popup показывают иерархию; удаление родительской папки переносит вложенные папки и все их вкладки в «Все»

### UX и навигация

- [x] **Клавиатурная навигация по view** — стрелки (↑↓←→) по карточкам (зациклено, учитывают фильтр папки и поиск), Enter → открыть, Delete/Backspace → удалить (с подтверждением), Esc → сброс (поиск, фильтр папки, выбор, активная карточка). Активная карточка подсвечена оранжевым контуром. Не перехватывает, пока фокус в поле ввода или открыта модалка; Esc из поля поиска тоже сбрасывает всё
- [x] **Массовое открытие** — чекбоксы на карточках + плавающая панель «N выбрано / Открыть / Сбросить»; «☑ Выбрать» в шапке выбирает/снимает все видимые; клик по открытой вкладке снимает выбор; изменение storage сбрасывает выбор; вкладки открываются неактивными
- [x] **Горячие клавиши** — Ctrl+Shift+S (manifest `commands.save-tab`, suggested key «Ctrl+Shift+S», description по-русски) — сохранение текущей вкладки; background.js слушает `chrome.commands.onCommand`, chrome:// URL пропускаются (тот же save-current путь: дедупликация по URL, folderId по умолчанию null)

### Умные фичи

- [x] **Автосохранение при закрытии** — `chrome.tabs.onRemoved` → архив закрытых вкладок: закрытие браузерной вкладки, чей URL есть среди сохранённых, ставит `archivedAt` (timestamp) на сохранённую вкладку (folderId/tagIds не трогаются; повторное закрытие обновляет `archivedAt`, дублей не создаётся; несуществующий URL — noop). В view архивные карточки приглушены (класс `archived`, `--archived-opacity`), на них кнопка «↩» возвращает вкладку (снимает `archivedAt`); чип «🗄 Архив» в шапке фильтрует на архив (toggle, Esc сбрасывает). `archivedAt` — поле вкладки, поэтому экспорт/импорт JSON переносит его
- [x] **Сессии** — группировка вкладок по сессиям (время + контекст): ключ `blattam-sessions` (`chrome.storage.sync`), сессия = `{ id, name, createdAt, tabUrls }` — именованная группа сохранённых вкладок. В шапке «📋 + Сессия» (рядом с папками/тегами) → модалка с именем (пусто → «Сессия ДД.ММ»); по умолчанию сессия захватывает ВСЕ сейчас видимые вкладки (с учётом фильтров). Ряд сессионных чипов (отдельный ряд под тегами, префикс «📋»): клик фильтрует на вкладки сессии (комбинируется с папкой/тегом/поиском), «+» на чипе добавляет сейчас видимые в сессию (без дублей), «✕» удаляет сессию (с confirm)
- [x] **Рекомендации** — «Часто открываемые» и «Избранные» на основе истории: ключ `blattam-stats` (`chrome.storage.local`, per-device, прунинг до 500 URL по `lastOpened`): `{ url: { opens, lastOpened } }`. Инкремент при каждом открытии сохранённой вкладки (единый хелпер `createTabFromSaved` в background.js: пути open-one / open-many / open). В шапке view два спец-чипа: «⭐ Частые» (top-20 по `opens`, только `opens >= 2`) и «🕘 Избранные» (top-10 по `lastOpened` за последние 7 дней); клик фильтрует на этот набор (комбинируется с другими фильтрами), повторный клик — сброс; Esc сбрасывает

## 🎨 Дизайн

- [x] **Дизайн-токены** — общий `theme.css` с CSS-переменными (палитра, текст, границы, акцент, тени). view.html + popup.html используют только `var(--*)`, в `<style>` не осталось жёстких hex. Тёмная тема = переопределение переменных в `[data-theme="dark"]` (без перебора). Визуальный дифф нулевой — подтверждено пиксель-в-пиксель до/после
- [x] Тёмная тема (toggle в header) — кнопка 🌙/☀️ в шапке view.html; состояние в `chrome.storage.local` под ключом `blattam-theme` ('dark'/'light', по умолчанию светлая); тема применяется до первого рендера (без мигания)
- [x] Адаптивные размеры карточек (крупный / компактный режим) — кнопка ▦/▤ в шапке view.html; состояние в `chrome.storage.local` под ключом `blattam-card-size` ('large'/'compact', по умолчанию 'large'); компактный режим = класс `compact-cards` на body + переопределение токенов размеров (`--card-min`, `--card-gap`, `--card-name-size` и т.п.) — меньше карточки, шрифт, отступы, больше колонок; применяется до первого рендера; Esc НЕ сбрасывает размер
- [x] Скриншоты вкладок на карточках (`chrome.tabs.captureVisibleTab`) — при сохранении вкладки (popup + hotkey) снимается скриншот, даунскейлится до ~160px на offscreen canvas и пишется в `chrome.storage.local` под ключом `blattam-screenshots` (`{ tabId: dataUrl }`); вкладка хранит только `hasScreenshot`; на карточке — `<img>`-миниатюра сверху (lazy load после первого рендера); chrome:// и chrome-extension:// не снимаются; сбой capture не ломает сохранение; удаление вкладки чистит скриншот (view-путь — в view.js, background-путь — в background.js)
