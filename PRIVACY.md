# Политика конфиденциальности

BlatTabs — браузерное расширение (Chrome / Opera, Manifest V3) для управления сохранёнными вкладками. Расширение не содержит аналитики и телеметрии и не обращается ни к каким внешним серверам, кроме GitHub — и только после вашего явного подключения аккаунта.

Обновлено: 23.11.2026

## 1. Данные только на вашем устройстве (chrome.storage.local)

Хранятся в локальном хранилище браузера и никуда не отправляются:

| Ключ | Что хранит |
|---|---|
| `blattam-tabs` | Список сохранённых вкладок: имя, URL, favicon, пространство, группа, комментарий |
| `blattam-trash` | Корзина: удалённые вкладки (до восстановления или «Удалить навсегда») |
| `blattam-browser-tabs` | Зеркало открытых вкладок вашего браузера для правой рейки (инкогнито-вкладки не попадают) |
| `blattam-theme`, `blattam-lang`, `blattam-quick-search` | Тема, язык интерфейса, тумблер быстрого поиска |
| `blattam-bg-image`, `blattam-bg-image-left`, `blattam-bg-image-right` | Картинки-фоны (центр / левая / правая рейка) |
| `blattam-tab-color`, `blattam-custom-theme`, `blattam-presets`, `blattam-active-preset` | Кастомный цвет карточек, кастомизация внешнего вида, пресеты внешнего вида |
| `blattam-hotkeys` | Назначенные горячие клавиши |
| `blattam-data-updated-at` | Метка времени локальных данных (служебная, для синка) |
| `github-token`, `blattam-github-login`, `blattam-auth-scope`, `blattam-gist-id` | Токен GitHub, кэш имени пользователя, служебные данные входа (только при подключённом аккаунте) |

Токен GitHub имеет минимальный scope `gist` (чтение и запись одного приватного Gist). Он хранится только в `chrome.storage.local`, используется исключительно в запросах к `api.github.com` от вашего имени и **не входит** в синк-пейлоад.

## 2. Синхронизация самим браузером (chrome.storage.sync)

Ключи `blattam-spaces`, `blattam-groups`, `blattam-last-space` (пространства, группы, последнее активное пространство) лежат в `chrome.storage.sync`. Их синхронизирует между устройствами **сам браузер** через ваш аккаунт Google, если вы в него вошли. Расширение лишь читает и записывает эти ключи; механизм синка браузера не меняется.

## 3. GitHub — только после явного «Войти в GitHub»

Пока вы не подключите GitHub-аккаунт (карточка «Аккаунт» в левой рейке), расширение не отправляет данные в сеть.

После подключения данные хранятся в вашем **приватном Gist** (создаётся автоматически при первом синке; файл `sync.json`, описание «BlatTabs Sync Data», ID Gist хранится на устройстве):

- **Состав** — только: список вкладок, пространства, группы, последнее пространство и метка времени (явный whitelist; настройки, тема и токен не входят).
- **Push (в облако)** — автоматически после изменений (дебаунс; в unpacked-расширении Chrome — до ~1 минуты) и по кнопке «Синхронизировать».
- **Pull (из облака)** — только по вашему явному действию (кнопка «Синхронизировать»).
- **«Очистить облачные данные»** — содержимое Gist становится пустым (данные удаляются с GitHub).
- **«Отключить»** — токен удаляется с устройства; сам Gist остаётся в вашем аккаунте GitHub — при желании удалите его вручную.

Все сетевые запросы расширения:

| Куда | Когда |
|---|---|
| `api.github.com` (Gist, проверка аккаунта) | при подключённом аккаунте |
| `github.com` (страницы входа: OAuth / Device Flow) | только в момент подключения |
| Страница GitHub Releases | по вашей кнопке «Открыть страницу Releases» |

Никаких других сетевых запросов, аналитики, телеметрии и внешних серверов нет.

## 4. Удаление данных

- **На устройстве** — данные расширения удаляются в `chrome://extensions` (кнопка «Удалить данные» / «Удалить» у BlatTabs).
- **В GitHub** — кнопка «Очистить облачные данные» (Gist пустеет) и/или удаление Gist в вашем аккаунте GitHub (Gist → «BlatTabs Sync Data»).
