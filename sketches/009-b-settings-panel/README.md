# Sketch 009-B — «Панель настроек» (content-dominant product panel)

Теряемый дизайн-прототип: newtab BlatTabs, переложённый в **трёхколоночный
рабочий стенд** («workbench»). Один самодостаточный файл `index.html` (без
внешнего JS, без `chrome.*`; единственный внешний ресурс — Google Fonts «Geist»).
Открывается напрямую (`file://`) или через `python -m http.server`.

## Станция дизайна: контент-доминантная продуктовая панель

Главная идея — вкладки остаются **героем** страницы (центральная колонка ~75%
ширины, визуально верна `view.html`), а всё «настроечное» уходит в **просторную
правую панель** с продуктовым ощущением (Linear/Vercel: скруглённые карточки-секции,
воздух, тёплый акцент). Левая колонка — тонкая почти пустая иконно-рейка «на вырост».

### Ключевые решения

- **Хедер (полная ширина, sticky).** Логотип `BlatTabs` слева, центрированный поиск
  (иконка + поле + `kbd /`), справа — пара компактных иконок (⚙ Настройки, ⋯ Ещё).
  Экспорт/импорт/тема убраны из шапки — они живут в правой панели.
- **(a) ЛЕВАЯ — тонкая иконно-рейка (56px), по сути пустая.** Два приглушённых
  заглушки-вкладки/пространства (faint, `opacity:.5`, верх) + бледная аватарка внизу.
  Сигнал «будущее», а не рабочая навигация. Тонкая hairline справа.
- **(b) ЦЕНТР — доминирующая рабочая зона (~1088px / ~75%).** Ряд space-чипов
  (Работа/Личное/Книги + «+ Пространство»), мета-строка «Мои вкладки · N» и сетка
  tab-карточек с заголовками групп (gbar) — **визуально 1:1 к `view.html`**
  (те же токены, min-width 141px, карточки с фавиконом-заглушкой и 2-строчным именем,
  1px-линия сверху шапки группы, «БЕЗ ГРУППЫ» + «+ Группа»).
- **(c) ПРАВАЯ — панель настроек (296px), «дышащая», скруглённая.** Отдельная
  поверхность (`--surface`) с левой hairline; каждая секция — скруглённая карточка
  (radius 12, лёгкий фон `--card-bg`, `--line`):
  - **Тема** — *сегментированный* переключатель (Светлая / Тёмная / Система).
    Активный сегмент заливается **тёплым тоном drag-ghost** (`--ghost-bg` /
    `--ghost-ring`). Клик реально переключает тему: `light`/`dark` — фикс,
    `system` — по `prefers-color-scheme` (слушает `matchMedia`).
  - **Данные** — две полноширинные кнопки («Экспортировать JSON» / «Импортировать
    JSON»), каждая с однострочным подзаголовком.
  - **Аккаунт** — круглая аватарка-заглушка, строка «Гостевой режим», тёмная
    CTA-кнопка «Войти в аккаунт» (`--ink`) и бледная заметка
    «Синхронизация между устройствами — скоро».
  - **2 инертные строки-списка** (Язык → «Русский», Горячие клавиши → «/ поиск»)
    с иконкой, значением и шевроном; hover-подсветка.
- **Тёплая палитра.** Светлая/тёмная темы — точные токены `theme.css`. Тёплый
  drag-ghost-тон (`#fbe3b6`/`#d99a4e` light, `#4c3c22`/`#d7a24d` dark) — единственный
  акцент: активный сегмент темы + маркер «скоро».

### Как отличается от «просто сайдбара»

Тонкая **левая** рейка (56px, почти пустая) vs просторная **правая** панель (296px,
скруглённые карточки, воздух); **сегментированный** (не switch) переключатель темы
с тёплым активным состоянием; продуктовый ритм отступов (padding 14–22, gap 12,
radius 12/9/8). Центр остаётся доминирующим — настраиваете сбоку, работаете в центре.

### Запуск
```
cd sketches/009-b-settings-panel
python -m http.server 8792 --bind 127.0.0.1
# → http://127.0.0.1:8792/index.html
```

### Компромиссы
- Карточки/чипы — статичная демонстрационная вёрстка (без drag-and-drop, выбора и
  модалок из `view.js`) — это про компоновку и правую панель, не про поведение.
- Сегмент «Система» следует OS-теме браузера; аватарка, кнопки Данные/Аккаунт и
  строки списка — инертные (mockup).
- Левая рейка намеренно пустая: она обозначает будущее расширение, а не функцию.
