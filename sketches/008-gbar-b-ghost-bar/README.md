# Sketch 008-B — group header

## Станция: Призрачная плашка (ghost bar)

Станция дизайна: группа — та же геометрия, что и у нынешней плашки (полная ширина, 28px, drag-таргет без изменений), но вместо тёплой подложки — нейтральный тон карточек, так что заголовок читается как тихая надпись, а не как панель.

### Ключевые решения

- **Layout**
  - Бар без изменений в геометрии: `grid-column: 1/-1`, высота 28px, `padding: 0 10px`, radius 6px; hit-area для drag та же, что и сейчас.
  - Внутри — одна строка: chevron ▾/▸, название группы, счётчик «N вкладок»; при ховере справа появляются ☑ ✎ ✕ (`margin-left: auto`).
- **Typography**
  - Chevron — 10px mono, `--text-faint`.
  - Название — 12.5px/500, `--text-muted` (приглушённое, не полный ink); при ховере сдвигается на `--text-soft` — единственный заметный отклик.
  - Счётчик — 10.5px mono, `--text-faint`.
- **Color**
  - Постоянный фон = `var(--card-bg)` (#f5f5f5 light / #36312d dark) — тот же нейтральный тон, что у карточек; рамка и тёплый акцент убраны.
  - Ховер: лёгкая затемняющая плёнка — `rgba(0,0,0,0.03)` в light / `rgba(255,255,255,0.03)` в dark.
  - Кнопки ☑ ✎ ✕: 18px круглые, прозрачные, `--text-faint`; «on»-состояние ☑ — фон `--ink`, глиф `--on-ink`.
- **Interaction**
  - Клик по бару — collapse/expand: карточки снимаются/вставляются в DOM, счётчик остаётся, chevron ▾↔▸.
  - Кнопки управления появляются по ховеру (fade 0→1); ☑ переключает косметическое «on»-состояние.
  - Позиция и размер бара как drag-таргета — без изменений.

### Компромиссы

- **Сильно** в: тихий плоский тон убирает визуальный шум — тёплая плашка перестаёт конкурировать с карточками; сетка читается как одна поверхность; реализация дёшевая (те же токены, без новых элементов).
- **Слабо** в: без рамки и контрастной заливки бар может «раствориться» в карточках и потерять ощущение drag-таргета; управление группой видно только при ховере — на тач-устройствах без hover кнопки фактически скрыты.

### Кому подходит

Пользователям, которым текущая плашка «кричит»: тем, кто хочет сетку максимально спокойной, а управление группой — вторым планом. Хорош как кандидат в «тихий режим» по умолчанию при большом числе групп.
