# Sketch 008 — Вариант C: «Чип» (inline chip)

Теряемый дизайн-прототип шапки группы для BlattamToby. Один самодостаточный файл: `index.html` (без внешних JS, без chrome.* API; единственный внешний ресурс — Google Fonts).

## Станция: Чип (inline chip)

**Станция дизайна.** Тихий тег, парящий над карточками группы: авто-ширинный inline-пиксель с hairline-контуром и прозрачным фоном — не полноширинный баннер.

### Ключевые решения

- **Layout.** Шапка — элемент грида `grid-column: 1/-1` с `justify-self: start; width: fit-content`: пиксель обнимает контент (примерно 120–150px), прижат влево, top-margin 4px. Не перекрывает всю строку и не растягивается на ширину колонки.
- **Typography.** Имя группы 12px/500 (`--text-soft`), шеврон ▾/▸ 9px mono и счётчик «N вклaдок» 10.5px mono (`--text-faint`). Единая тихая иерархия; на шаг мельче заголовка карточки — шапка подчинена контенту.
- **Color.** Прозрачный фон; 1px `var(--line)` — та же hairline, что у карточек. Тёплая заливка (`--gbar-bg`) убрана полностью. Hover: фон `var(--hover)`, имя → `--text`.
- **Interaction.** Клик по пилю → сворачивание/разворачивание: карточки удаляются/вставляются в DOM, счётчик остаётся на пилю, шеврон меняется ▾↔▸. По hover внутри пилю (после 1px-разделителя) проявляется набор ☑ ✎ ✕ (14px круглые, `--text-faint`); у ☑ есть состояние «on» (фон `--ink`, глиф `--on-ink`). Реальные hover-состояния у карточек, space-чипов и кнопок сверху; переключатель темы 🌙/☀️.

### Компромиссы

- **Сильно в:** визуальный вес — шапка группы перестала быть конкурирующей поверхностью; иерархия несётся позицией и hairline-контуром, а не цветом; одинаково тихо работает в light/dark без донастройки тёплого цвета; ширина адаптируется к имени группы (fit-content, эллипсис при 280px).
- **Слабо в:** hit-target мал (≈140×26px против 32px полного бара) — сложнее заметить и попасть при сканировании; управление скрыто до hover (нет постоянного аффорданса); при многих группах подряд чипы выглядят чуть разрозненнее, чем баннеры.

### Кому подходит

Тем, кто хочет видеть вкладки как «стену карточек» с тихим маркером «главы», а тёплый полноширинный бар — слишком громким. Хорошая середина в сторону «меньше, но на месте»: группа остаётся видимой (обведённая пилю), но отказывается от заливки.
