# Вариант A — «Штрих» (hairline label)

## Станция: Штрих (hairline label)

### Станция дизайна
Заголовок группы — не заполненный блок, а тихая типографическая строка, отделённая от соседних секций одной тонкой линией (hairline) и набором знаков.

### Ключевые решения
- **Layout**: строка заголовка занимает всю ширину сетки (`grid-column: 1/-1`), высота 26px, контейнера нет — фон прозрачный; единственная «фигура» — 1px-линия `var(--line2)` сверху, на всю ширину.
- **Типографика**: шеврон ▾/▸ — 10px mono, `--text-faint`; название группы — 12px/500, `--text-soft`; зазор 8px; счётчик «N вкладок» — 10.5px mono, `--text-faint`. Всё меньше карточки — иерархия держится на кегле и весе, а не на подложке.
- **Цвет**: никаких заливок (токены `--gbar-bg` не используются). Единственное состояние — hover: едва заметный фон `var(--hover)` на всю строку.
- **Интерактив**: клик по строке сворачивает/разворачивает группу (карточки убираются/возвращаются в DOM, счётчик остаётся, шеврон переворачивается ▾↔▸); на hover плавным fade-in появляются контролы ☑ ✎ ✕ справа (18px, круглые, `--text-faint`); ☑ переключает «on»-состояние (фон `var(--ink)`, глиф `--on-ink`).
- **Позиция**: секции разделяются типографикой и hairline, а не заполненной коробкой.

### Компромиссы
- **Сильно**: сетка выглядит как одно непрерывное поле, заголовки не конкурируют с карточками за внимание; hairline адаптивен в обеих темах через `var(--line2)`.
- **Слабо**: hairline очень светлый в светлой теме (`#ebebeb` на белом) — начало секции на беглом взгляде можно пропустить; строка без подложки воспринимается как «менее кликабельная», чем старая тёплая полоса; hover-фон слегка «материализует» строку — небольшой скачок контраста между состояниями.

### Кому подходит
Тем, кто хочет, чтобы newtab читался как тихий каталог: структура видна по ритму типографики, а не по декоративным блокам. Если хочется сильнее «каркаса» — нужны плотнее линии или смещённые вглубь лейблы (другие варианты).
